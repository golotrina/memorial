# Правило разработки Мемориала: ZERO-TRUST ARCHITECTURE

## Контекст (Product Matrix)
Сайт-мемориал является шаблоном для формы-конструктора, которая генерирует сайты для клиентов на тарифах: Freemium, PRO, VIP. 
Агентам, вносящим изменения в кодовую базу, строго запрещено использовать косметическое скрытие элементов (CSS `display: none` или JS-флаги) для разделения доступов к премиальным фичам.

## Главное правило (Физическая Обрезка)
1. **Модульность:** Любая новая премиальная функция (Например, Видео-плеер, 3D-древо, Ритуал свечей) должна писаться так, чтобы её HTML-блок, JS-логику и CSS-стили можно было легко и безопасно **физически вырезать** скриптом-генератором (Node.js).
2. **Отсутствие крашей:** Если генератор вырезает секцию `<section id="timeline">` из `index.html`, основной файл `app.js` не должен падать с ошибкой `null pointer`, пытаясь найти этот элемент. Добавляйте проверки `if (element) { ... }` на старте функций.
3. **Безопасность всех тарифов:** Клиент любого тарифа должен получить GitHub-репозиторий, в котором физически отсутствуют исходные коды VIP-модулей.
