# АРХИТЕКТУРА КОНСТРУКТОРА МЕМОРИАЛОВ (РАСПРЕДЕЛЕНИЕ ПО ТАРИФАМ)

На основе анализа базового кода `index.html` Мемориала Родителям, сайт был декомпозирован на независимые модули. 

Для автоматизации бизнеса и создания "Формы-конструктора", которая будет собирать сайт под клиента, мы жестко привязываем модули к тарифам. Это создаст ценность платных пакетов (апсейл).

## 🧩 Базовые модули (Доступны во всех тарифах, включая "Автономный старт")

Эти секции составляют скелет мемориала. Они генерируются для любого, даже бесплатного клиента.

1. **Header (Навигация):** Минималистичное меню, переключатель языков (RU/UA), смена темы (Светлая/Темная), управление размером шрифта.
2. **Hero Section (Главный экран):** Главное фото (или герб), Имя/Фамилия, годы жизни, короткая эпитафия (цитата).
3. **Parents / Bio Grid (Раздел биографии):** Базовые карточки с краткой биографией человека (или супругов). В бесплатной версии ограниченный объем текста.
4. **Footer (Подвал):** Копирайт, эпитафия от родственников, вотермарка создателя.

## ⭐ Модули уровня "Родовой архив PRO" ($188)

Эти секции требуют большего объема данных и скриптов. Клиент получает их только при оплате коммерческого тарифа.

1. **Timeline (Линия Жизни / Эпоха):** Интерактивная хронология жизни. В коде это `<section id="timeline">`. Модуль подтягивает исторические факты, места учебы, работы, переезды из JSON файла.
2. **Ritual (Свеча Памяти):** Модуль интерактивных соболезнований `<section id="ritual">`. Позволяет посетителям "зажечь" 3D-свечу (разные виды пламени) и оставить текстовое воспоминание.
3. **Tombstone Photo (Фото памятника):** Блок с фотографией реального физического захоронения.
4. **DNA & Ethnicity (Этническое наследие):** Блок со статической инфографикой (в формате WebP, согласно нашему архитектурному манифесту), показывающий происхождение предков без увода на внешние сайты.
5. **Admin Panel (Режим редактора):** Встроенная панель `div class="admin-panel"` для редактирования текстов прямо на сайте и генерации QR-кода на лету.

## 💎 Модули уровня "Цифровое Сияние VIP" ($888+)

Премиальные функции, требующие глубокой интеграции архитектурных решений (Zero-JS видео, Web3) и работы парсера.

1. **The Agelong Tree (Интерактивное Древо Рода):** 
   - *Технология:* Автономный скрипт на базе SVG/JS, получающий данные из локального `tree.json`.
   - *Функция:* Кликабельное визуальное древо, без внешних ссылок на MyHeritage.
2. **Zero-JS Video Modals (Видео-хроника):** 
   - *Технология:* Нативные HTML5 теги `<dialog>` с видео `preload="none"`. Триггером выступают эстетичные инлайн-ссылки `<span class="inline-video-trigger">`.
   - *Функция:* Просмотр семейных архивных видео прямо поверх "Линии Жизни" с размытием фона, без расхода лишнего трафика.
3. **Web3 Backup (Блок вечного хранения):** Блок в футере, выводящий Arweave Hash (вечную ссылку на блокчейн-копию мемориала) для будущих поколений.

### Инструкция для будущей Формы-Конструктора:
Когда мы будем программировать интерфейс для вас (как для владельца агентства), форма будет работать так:
1. Вы вводите данные клиента.
2. Ставите галочку тарифа (например, `PRO`).
3. Скрипт-генератор (на Node.js) берет наш базовый `index.html` и автоматически **вырезает** из него HTML-блоки VIP уровня, оставляя только Base и PRO. 
4. Облегченный код пушится в репозиторий клиента на GitHub. 

Это 100% гарантия того, что бесплатный клиент не получит премиум-функции, а исходный код репозитория останется легким и чистым.
