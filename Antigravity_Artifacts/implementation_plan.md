# План создания базы знаний TanGo Digital Studio

## Цель
Трансформировать массив сырых данных (более 400 000 символов диалогов) в профессионально структурированную, двуязычную базу знаний из 5 документов для идеальной работы с ИИ в будущем.

## Утвержденные вводные
1. **Язык**: Двуязычный подход (Русский основной + английский для ключевых технических терминов/названий).
2. **Детализация**: Концептуальное описание + точные фрагменты кода (JSON конфигурации, CSS переменные, API).
3. **Процесс**: Строго последовательное создание документов (по одному).
4. **Контекст**: Файл `business_roadmap.md` остается самостоятельным документом.
5. **Качество**: Многоуровневый анализ супер-агентами для 100% покрытия деталей.

## Структура Базы Знаний (5 документов)

### 1. `01_VISION_AND_BRAND.md` (Видение, миссия и философия)
* Манифест основателя («Архитектор Цифрового Наследия»)
* Философия «цифрового бессмертия» и позиционирование бренда (Tango Digital Studio)
* УТП (Уникальное торговое предложение) и психологические триггеры
* Целевая аудитория и зоны ответственности (клиент vs студия)
* Бэкграунд основателя как ключевой фактор доверия

### 2. `02_TECHNICAL_ARCHITECTURE.md` (Техническая архитектура и код)
* Модель хостинга (GitHub Pages, Serverless) и безопасность
* Структура шаблонов (config.json, CSS-переменные, JS-логика)
* Система локализации (i18n, Google Translate API)
* Оптимизация медиафайлов (WebP, сжатие на лету)
* Генеалогические форматы (GEDCOM, ИИ-парсинг, интеграция с «Древо Жизни»)

### 3. `03_BUSINESS_AND_TARIFFS.md` (Бизнес-модель и тарифы)
* Детальная сетка тарифов («Автономный старт», «Семейный архив», «VIP Мемориал»)
* Цены, ограничения и включенные фичи для каждого тарифа
* Монетизация дополнительных услуг (upsells)
* Интеграция физических носителей (QR-таблички из каленого стекла)

### 4. `04_SECURITY_AND_WEB3.md` (Безопасность, автономность и Web3)
* Защита от банов GitHub и спама (Rate limits, кастомные домены)
* Мульти-облачное резервирование (GitLab, Internet Archive / Wayback Machine)
* Web3 хранилища (Arweave) и домены (ENS .eth, Unstoppable Domains)
* Цифровые памятные медали (POAP / NFT на Polygon)
* Политика цифрового завещания и передачи ключей

### 5. `05_OPERATIONS_AND_LEGAL.md` (Операционные процессы и юриспруденция)
* Legal Framework: ФОП, Публичная Оферта, Privacy Policy, Terms of Service
* Клиентский путь (Onboarding, валидация форм)
* Панель администратора (Telegram bot) и процессы апгрейда
* Скрипты автоматизации и пайплайны (n8n, webhook интеграции)
* Копирайты, торговые марки и вопросы патентования

## Процесс реализации
1. **Глубокий анализ** тремя параллельными ИИ-агентами (В ПРОЦЕССЕ)
2. **Кросс-чек** извлеченных данных.
3. Генерация документов `01` -> `05` поочередно.
4. **Финальный аудит** и выводы по концепции бизнеса.
5. **Экспертные рекомендации** по улучшению слабых мест.
