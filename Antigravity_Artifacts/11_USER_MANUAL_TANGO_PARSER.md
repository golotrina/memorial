# РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ: TANGO DATA-ANCESTOR (tango_app.py)

Этот документ является практическим руководством для операторов агентства TanGo Digital Studio по работе с графическим интерфейсом ИИ-парсера генеалогических данных.

---

## 1. Вкладка "🔗 Аудит и Склейка"
Эта вкладка предназначена для слияния новой обогащенной базы (например, ветки Лапиных) с вашим Эталоном (Мастер-графом Голотриных) методом безопасной хирургической инъекции (Append-Only). 

### 1.1 ВАЖНОЕ ПРАВИЛО: Порядок выбора файлов (Не перепутайте!)
Для корректной работы программы критически важно правильно распределить файлы по полям. Если вы перепутаете их местами, программа сломает внутренние связи Эталона, и ваше Древо распадется на куски!

*   **Верхнее поле (Эталонная база / Master):** Сюда помещается ТОЛЬКО ваш огромный, основной, вылизанный файл-эталон (например, `Голотрины и Петковы 1208 2026.ged`). Это фундамент, к которому мы приклеиваем новые данные.
*   **Нижнее поле (Новая выгрузка / New):** Сюда помещается ТОЛЬКО маленький "свежий" файл, который мы хотим влить в Эталон (например, `test_vip.ged` или `Client_New_Family_VIP.ged`).

### 1.2 Правильный порядок действий (Идеальный сценарий):
1. Нажмите кнопку **"📁 Выбрать GEDCOM файлы"** и загрузите файлы строго в указанном выше порядке.
2. ⚠️ **ОБЯЗАТЕЛЬНЫЙ ШАГ:** Нажмите синюю кнопку **"🔍 НАЙТИ СОВПАДЕНИЯ (Ассистент)"**.
3. Дождитесь, когда ИИ проанализирует базы и выдаст в текстовое окно список кандидатов на слияние (с вопросительным знаком `?`).
4. Отредактируйте этот список: удалите знаки `?` для подтвержденных персон и сотрите ошибочные строки. Оставьте только чистые совпадения (например: `Иван Иванов = Иван Иванов`).
5. Только после этого нажмите золотую кнопку **"🛠 ЗАПУСТИТЬ АУДИТ И СКЛЕЙКУ"**.
6. Итог: Программа бережно вольет новые данные в Эталон и сохранит результат в папке `Tango_Results/2_Merge/MASTER_FAMILY_VIP.ged`.

## 2. Разбор ошибок и нештатных ситуаций (Troubleshooting)

### 2.1 Ошибка: Нажали "Запустить склейку", пропустив шаг "Найти совпадения"
**Симптомы:** Вы выбрали два файла, забыли нажать синюю кнопку и сразу кликнули по золотой кнопке запуска склейки.

**Что произошло под капотом:**
* Вашим исходным файлам **ничего не угрожает** (они никогда не перезаписываются).
* Программа создала файл `MASTER_FAMILY_VIP.ged`, но поскольку вы не дали ей правил, кого с кем склеивать, она просто свалила всех людей из обеих баз в одну кучу.
* В результате в итоговом файле ни одна семья не объединилась, а у общих персон появились "клоны" (например, в древе стало две независимые Светланы).

**Как исправить (План действий):**
Вам не нужно закрывать программу, удалять файлы вручную или отменять действия.
1. Прямо в открытом окне вернитесь на шаг назад: нажмите синюю кнопку **"🔍 НАЙТИ СОВПАДЕНИЯ (Ассистент)"**.
2. В текстовом окне появится список совпадений. Отредактируйте его, оставив только верные пары.
3. Снова нажмите золотую кнопку **"🛠 ЗАПУСТИТЬ АУДИТ И СКЛЕЙКУ"**.
4. Программа автоматически и бесшовно перезапишет ошибочный файл `MASTER_FAMILY_VIP.ged` на правильный. Склейка восстановлена!
